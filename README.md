# East China Odyssey, 15-26 November 2026

**Pearls, Peaks & Porcelain.** Trip briefing for the travelling group: Shaoxing, Huangshan, Jingdezhen and Shanghai.

**Open the briefing:** https://lohchingsoo.github.io/east-china-odyssey/

## What's inside

- Stylised route map, hotels (Chinese names, map and website links) and a transport timetable
- Day-by-day plan, with the story behind each place
- Background reading on the Grand Canal, pearls and blue-and-white porcelain
- Practical tips: entry, payments, connectivity, power banks, weather, packing and food
- A tick-off checklist that saves on your own device
- Sources in APA 7 format

## Publishing on GitHub Pages

1. Create a public repository named exactly `east-china-odyssey` (the sharing preview depends on this name).
2. Upload `index.html`, `og-image.png` and this `README.md`.
3. Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute or two, the page is live at the address above. Share that link in the group chat.

The page asks search engines not to list it, but anyone with the link can open it. Share it only with the group.

Itinerary details come from the organiser and may change. The organiser's latest message wins.
